# Privacy-Preserving Vision Agent

A privacy-preserving browser vision agent that combines local sensitive-data detection and redaction with AI-powered visual page understanding. Sensitive information is detected and redacted locally in the browser before the sanitized screenshot is sent to the AI system.

### Current Implementation

* DOM-based page analysis
* Browser screenshot capture
* Local sensitive-data detection
* DOM-level redaction
* Screenshot-level redaction
* Secure transfer of sanitized screenshots to a local server
* Gemini Vision-based structured page analysis

### Privacy Principle

**Sensitive information is processed and redacted locally before visual data is sent for AI analysis.**
